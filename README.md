# Manejo-de-Excepciones
 Crear una aplicación en Windows Forms con C# que registre datos de un estudiante (como si fuera un formulario de inscripción), pero lo importante es que valide los datos y use manejo de errores (try-catch).
Herramientas Utilizadas :
C#

.NET Framework

Visual Studio 2022
